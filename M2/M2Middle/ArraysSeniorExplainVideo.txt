What is an array?
An array is a data structure that consists of elements of the same data type such as:
	integers, strings, characters, etc.
Each element in an array can be identified by the arrays index, which starts at 0
For example: here we have an integer array that holds 3 elements, 1 2 and 3, making the size of this array be 3, BUT the index for these elements go as 1 having an index of 0,
2 having an index of 1 and 3 having an index of 2.

When to use an array vs variable
Variables should be used if the data set are different data types
	For example: use variables if that data you are working with are integers and strings
An array should be used when holding data sets of the same data type
	This allows us to access the group data in any order
	For example: We can have an array of peoples ages, an array of colors and an array of test scores

How to Define arrays
	We can define single dimensional arrays by stating its data type followed by a set of square brackets
	For multidimensional arrays, we follow the same syntax as single dimensional arrays however we include another set of square brackets to define another dimension 
	in the array
